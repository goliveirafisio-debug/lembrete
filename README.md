# lembrete

App local de lembretes em formato mural de post-its, com "quitação" (marcar como resolvido).

- **Como abrir:** `Abrir-Lembretes.cmd` (ou o atalho "Meus Lembretes" na Área de Trabalho).
- **Stack:** app local, sem servidor externo.
- **Dados do usuário** ficam em `lembretes.json`, que **não é versionado** (ver `.gitignore`) — este repositório é público e nunca deve conter dados reais.
